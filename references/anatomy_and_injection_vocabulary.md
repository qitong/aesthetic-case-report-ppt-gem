# Medical Aesthetics Case Report Vocabulary & Lexicon
# 医美临床病例报告解剖学、注射技术与流变学中英文词汇库

## 1. 颜面解剖与层次术语 (Facial Anatomy & Layers)

### 1.1 面部五层结构 (Five Facial Layers: Superficial to Deep)
| 层次 | 英文术语 | 中文术语 | 注射技术要点与解剖特征 |
| :--- | :--- | :--- | :--- |
| **Layer 1** | Skin (Epidermis & Dermis) | 皮肤（表皮与真皮） | 浅层水光、微滴注射（Micro-droplets）、浅层细纹淡化 |
| **Layer 2** | Superficial Fat Compartments | 浅层脂肪室 | 包括鼻唇沟脂肪垫、眶下浅脂肪垫等；老化常伴下移与堆积 |
| **Layer 3** | SMAS & Mimetic Muscles | 表浅肌肉腱膜系统与表情肌 | 动力性皱纹发生层，神经肌肉调控（肉毒素），解剖分界标志 |
| **Layer 4** | Deep Fascial Spaces / Retaining Ligaments | 深层潜在间隙与支持韧带 | 关键天然安全间隙（如 Prezygomatic space, Premaxillary space）；韧带起到锚定作用 |
| **Layer 5** | Periosteum & Deep Fat Pads | 骨膜与深层脂肪垫 | 骨相强支撑注射层（如 DMCFP 深层内侧颊脂肪垫、SOOF、骨膜上深层骨相重塑） |

### 1.2 关键支持韧带与解剖标志 (Ligaments & Landmarks)
- **ORL (Orbicularis Retaining Ligament)**: 眶轮匝肌支持韧带（眼周注射关键分界，决定泪沟向睑颧沟延伸形态）
- **TTL (Tear Trough Ligament)**: 泪沟韧带（真性韧带，紧密附着于上颌骨眶下缘内侧）
- **AM (Arcus Marginalis)**: 弓状缘（眶隔在眶骨边缘的增厚纤维附着线）
- **ZCL / ZRL (Zygocutaneous / Zygomatic Retaining Ligament)**: 颧皮韧带 / 颧支持韧带（颧骨区面部提升锚定点）
- **PMCL (Platysma-Mandibular Cutaneous Ligament)**: 颈阔肌下颌皮韧带（下颌缘紧致与木偶纹区解剖界限）
- **DMCFP (Deep Medial Cheek Fat Pad)**: 深层内侧颊脂肪垫（中面部容量缺失核心填充区）
- **SOOF (Sub-Orbicularis Oculi Fat)**: 眶轮匝肌下脂肪（分为内侧与外侧 SOOF，深层眼眶周支撑）
- **ROOF (Retro-Orbicularis Oculi Fat)**: 眉下眶轮匝肌后脂肪垫（上睑与眉弓支撑）

## 2. 临床分型与评估量表 (Clinical Classification & Scales)

### 2.1 泪沟与眶下分型 (Tear Trough Classification)
- **Innie 型 (内陷型)**: 弓状缘（AM，眶隔附着点）与泪沟韧带（ORL/TTL）起点在眶缘上**分离**（间隙明显，AM 更偏向眶骨内缘/后方）。临床表现为深陷型泪沟，特别是向上看（Upgaze）时凹陷更深；适合深层支撑联合浅层融合。
- **Outie 型 (平齐/外展型)**: 弓状缘（AM）与韧带起点在骨表面几乎**重合**。临床表现为韧带附着浅，传统平行线状推注易在动态微笑时发生局限性隆起（“香肠样畸形” Sausage Deformity）。
- **Tear Trough Deformity Grades (Hirmand 分级)**:
  - Class I: 仅局限于内侧泪沟轻度凹陷。
  - Class II: 凹陷延伸至外侧中睑，伴有眶下颊部容积轻度不足。
  - Class III: 全眶下凹陷，伴随显著的眶骨下缘外露与颊部大面积容量缺失。

### 2.2 面部美学评估量表 (Facial Assessment Scales)
- **FAS (Facial Assessment Scale)**: 面部多区域量化评估表（上睑、眶下、前颊、侧颊、下颌等 0-4 分级）。
- **GAIS (Global Aesthetic Improvement Scale)**: 全局美学改善量表（Very Much Improved / Much Improved / Improved / No Change / Worse）。
- **Merz Scale / Allergan Scale**: 额纹、鱼尾纹、鼻唇沟、下颏退缩标准化五级摄影评价体系。

## 3. 注射术式与技术参数 (Injection Techniques & Parameters)

### 3.1 进针工具与方式
- **Sharp Needle (锐针)**: 常用 27G / 30G，多用于骨膜上精准单点垂直推注（Bolus）、微量定点支撑（Bone Depot）。
- **Blunt Cannula (钝针)**: 常用 25G / 27G 38mm-50mm，多用于间隙剥离、扇形铺展（Fanning）、线状逆行或顺行平铺（Linear Threading）。
- **Dual-Plane / Two-Step Technique (双平面/两步法)**:
  - Step 1: **Deep Support (深层支撑)** - 骨膜上或深层间隙内（如 DMCFP/Prezygomatic space）大颗粒强支撑性产品，纠正基底骨相及深层容积不足。
  - Step 2: **Superficial Blending (浅层融合/过渡)** - 穿透韧带筋膜在浅层或皮下微量彗星状/羽毛状铺展，平滑过渡交界线，避免静态楞与动态条索。

### 3.2 流变学特性与选品匹配 (Rheology & Product Selection)
| 流变学指标 | 英文符号/定义 | 临床意义 | 适用部位与层次 |
| :--- | :--- | :--- | :--- |
| **弹性模量** | $G'$ (Elastic Modulus / Storage Modulus) | 抗形变与垂直支撑能力 | 高 $G'$ 适用于骨膜上支撑（颧弓、下颌骨、鼻小柱、深层内侧颊） |
| **粘性模量** | $G''$ (Viscous Modulus / Loss Modulus) | 能量耗散与流动性 | 反映产品抵抗剪切蠕变性能 |
| **损耗角正切** | $\tan \delta = G''/G'$ | 弹性与粘性之比，值越小越偏弹性固态 | 低 $\tan \delta$ 产品支撑成型力强，不易移位 |
| **内聚力** | Cohesivity | 分子间聚合紧密度，抗外力挤压扩散性 | 高内聚力产品组织结合性好，适合动态表情活跃区 |
| **吸水膨胀率** | Swelling Factor / Hydrophilic Index | 术后吸水肿胀风险 | 眼周眶下必须选用低吸水性产品，预防术后晨起水肿与廷德尔效应（Tyndall effect） |

## 4. 并发症与安全性考量 (Safety & Complications)
- **Sausage-like Deformity (香肠样畸形/条索)**: 填充过浅或韧带阻挡导致浅层形成纵向或横向条状隆起，动静失调。
- **Tyndall Effect (廷德尔现象)**: 浅层注射过量透明质酸引起光散射，呈现蓝灰色透光阴影。
- **Malar Edema (颧部水肿)**: 阻碍眶周淋巴回流引发的持续性下睑及外侧眶周浮肿。
- **Vascular Occlusion (血管栓塞)**: 警惕眶下动脉、面动脉、角动脉等高危血管解剖变异，强调抽吸、低压慢推、微量多点。
